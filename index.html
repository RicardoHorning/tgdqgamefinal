01. O desafio: Crie o seu Game de Dados

Vocês serão a equipe de criação de um novo jogo educativo no SENAI Afonso Pena! O objetivo é transformar a UC de Tratamento e Gerenciamento de Dados em um jogo super divertido.

💡 A Grande Ideia: Vocês não precisam saber programar! Vocês serão os Game Designers (definem o tema, as fases, os desafios de dados e a história inspirada em um jogo famoso), e a Inteligência Artificial (Gemini) será o Programador.
ETAPA 1

📋 Escolher & Planejar

Escolha um clássico (Super Mario, Show do Milhão, Pac-Man) e adapte para desafios de relatórios e planilhas.

ETAPA 2

🤖 Gerar com Gemini

Use os Prompts Turbinados da aba 04. O Gemini cria o código do jogo com cores chamativas e efeitos divertidos.

ETAPA 3

🌐 Publicar no GitHub

Suba o arquivo index.html no GitHub Pages para que qualquer pessoa consiga jogar pelo link.

ETAPA 4

🎤 Campeonato na Aula

Na próxima aula, a equipe jogará ao vivo na tela da sala e explicará o conteúdo de dados do jogo.


02. Ideias de Jogos Famosos adaptados para Dados

Escolham um estilo de jogo clássico que a equipe goste e adaptem para o mundo administrativo:

ESTILO SUPER MARIO

🍄 Data Bros: O Resgate do Relatório

O herói precisa avançar por fases (Fase 1: Erros de Digitação; Fase 2: Interpretação de Gráficos). A cada obstáculo superado ao responder corretamente, ele ganha cogumelos de pontos e chega ao castelo da Diretoria!

ESTILO SHOW DO MILHÃO

💰 O Quiz do Milhão Administrativo

Um jogo de perguntas e respostas valendo 1 Milhão em Pontos de Desempenho! O jogador enfrenta perguntas de média, porcentagens e gráficos, com ajuda da 'Diretoria' ou da 'Planilha Universitária'.

ESTILO PAC-MAN / RETRÔ

👾 Pac-Data: Caçador de Indicadores

O jogador precisa 'comer' as respostas certas de metas e porcentagens enquanto desvia dos 'Fantasmas da Inconsistência' (erros de digitação e planilhas desatualizadas).

ESTILO RPG / QUEST

🛡️ O Assistente Lendário (Quest da Empresa)

Um jogo de escolha onde o jogador é um jovem estagiário que precisa resolver mistérios nos dados da empresa para ser promovido a Gerente de Dados!


03. Roteiro Guiado de Planejamento

Preencham com cuidado este roteiro. Ele será a "receita" que o Gemini usará para criar seu jogo!

Dica: Deixe o nome bem chamativo e indique o estilo (ex.: "Super Data Bros: A Jornada das Planilhas" ou "Show do Milhão TGDQ").
Quais assuntos de dados vocês vão testar? (ex.: Erros em tabelas, Média/Mediana, Escolha do gráfico correto, Porcentagem de Vendas).
Quem é o jogador? Qual é a missão dele? (ex.: "Você é o Mário Administrador e precisa consertar os dados antes que o Bowser trave o sistema da empresa").
Como é a primeira fase? (ex.: O jogador vê uma tabela de compras e precisa encontrar a célula com valor errado para ganhar 100 moedas).
Como é o desafio do "Chefão"? (ex.: A diretoria pede um relatório e o jogador deve escolher entre Gráfico de Linha, Pizza ou Colunas para salvar o dia).
Como ganha ou perde? (ex.: Começa com 3 vidas / 3 tentativas; ganha 100 pontos por acerto; se errar 3 vezes é Game Over!).
Atenção: Após preencher, cliquem em "Salvar Planejamento em PDF" ou "Copiar Texto" para enviar ao Gemini na próxima etapa!

Planejamos um jogo educacional super divertido e gamificado sobre dados administrativos. Por favor, leia nosso planejamento abaixo e me confirme se entendeu a ideia antes de gerar o código: [COLE AQUI O SEU PLANEJAMENTO COPIADO DA ETAPA 3]

Etapa 2: Gerar o Código do Jogo + Tutorial de Publicação

Perfeito Gemini! Agora gere este jogo completo em um ÚNICO ARQUIVO chamado index.html (com HTML, CSS e JavaScript integrados no mesmo código). Requisitos Visuais e de Gameplay do Jogo: 1. DESIGN DIVERTIDO E GAMIFICADO: Use cores vivas, botões grandes e animados, barras de progresso, sistema de Vidas (❤️ ❤️ ❤️) e Placar de Pontos. Inspirar no visual do jogo clássico selecionado. 2. ESTRUTURA DO JOGO: Tela inicial com história e regras -> Fase 1 (Desafio de Dados Fácil) -> Fase 2 (Desafio de Dados Chefão) -> Tela de Vitória com confetes/animação ou Tela de Game Over com botão de tentar novamente. 3. CONTEÚDO ADM/DADOS: As perguntas e desafios de planilhas e gráficos devem seguir exatamente o planejamento enviado. 4. CÓDIGO ÚNICO: Entregue todo o código dentro de um único bloco ```html ... ``` sem depender de arquivos externos de imagem. IMPORTANTE: Ao final da resposta, após o código, inclua um tutorial em 5 passos bem simples (para quem não é de TI) de como criar o repositório no GitHub e ativar o GitHub Pages.

05. Publicar o Jogo no GitHub

Siga o passo a passo resumido ou leia as orientações que o próprio Gemini te deu no chat:

1

Copie o código do Gemini

No chat do Gemini, clique no botão de copiar o código HTML que ele gerou.

2

Crie o arquivo index.html

Abra o Bloco de Notas (ou VS Code), cole o código e salve no computador com o nome exato index.html.

3

Abra o GitHub

Acesse github.com e crie um novo repositório Público com o nome do seu jogo.

4

Faça o Upload

Clique em Add file > Upload files, arraste o seu arquivo index.html e clique no botão verde Commit changes.

5

Ative o GitHub Pages

Vá em Settings > Pages, selecione a branch main / root e clique em Save. Em 2 minutos o jogo estará online!

06. Testar e Validar o Jogo

Jogue o seu próprio jogo pelo link do GitHub Pages e marque o checklist antes da entrega final:

0 de 5 verificações concluídas
